# 🍜 ラーメン屋向けスマートPOSシステム (Ramen POS)

ReactとFirebase (Firestore) を用いて構築された、リアルタイム同期対応のモダンなラーメン屋向けPOS＆モバイルオーダー（QR注文）システムです。

客側のスマホからのQR注文（席番号自動取得）、メニューごとの柔軟なオプション選択、店側のキッチンディスプレイ（KDS）およびスタッフ向けお渡し待ち・会計管理まで、一連の店舗オペレーションを網羅しています。

---

## 🚀 主な機能・特徴

### 1. 顧客用モバイルオーダー画面 (`/`)

- **QRコードからの席番号自動取得**: URLパラメータ（例: `/?seat=3`）を読み取り、現在の注文席番号を自動で保持。
- **タブ切り替えメニュー**: 「すべて」「ラーメン」「サブメニュー（餃子・味玉等）」「ドリンク」をスムーズに切り替え。
- **リッチな商品個別モーダル**:
  - メニューをタップするとモーダルが開く。
  - **商品ごとの個別オプション**: 麺の固さ、大盛り（+150円）、チャーシュー枚数選択、二郎系の「野菜増・脂増・にんにく増」などの柔軟なカスタマイズに対応。
  - **リアルタイム金額計算**: オプション選択や個数変更に応じて、合計金額が即座にプレビュー表示される。
- **注文確認・カート管理**:
  - 選択したオプションの確認、個数の増減（1個で減らすと自動削除）、および総個数や合計金額の表示。
- **注文履歴**: ローカルストレージ（`localStorage`）を用いた当日の自分自身の注文履歴確認。

### 2. キッチンディスプレイ画面 (KDS) (`/kitchen`)

- **リアルタイム注文受信**: Firebase Firestoreの `onSnapshot` により、客が注文を確定した瞬間に厨房の画面へ音やリロードなしで即座に反映。
- **キッチン用略称表示**: 正式名称ではなく、厨房で判別しやすい略称（例：「ミソ」「醤油」）と、選択されたカスタムオプションが結合された文字列（例：「ミソ　大盛り　もやし増」）を表示。
- **商品ごとの調理完了トグル**: 各メニューの「未 / 完成」を個別に切り替え、全商品が揃うと「準備OK」ボタンが活性化。

### 3. スタッフ用お渡し待ち・会計管理画面

- **「席番号 # 注文番号」の視認性**: 例: `3 席 456` のように、どの席のどの注文かが一目で分かるレイアウト。
- **カード型縦積みリスト**: サムネイル、略称、数量、小計金額が綺麗に並び、下部に全体の合計金額を表示。
- **配膳・会計フロー**: 「配膳完了（会計へ）」ボタンを押すことで、お渡し待ちから会計完了・履歴へとスムーズに遷移。

## 🛠️ 技術スタック

- **Frontend**: React (Vite), React Router DOM, CSS Modules
- **Backend / Database**: Firebase (Cloud Firestore)
- **State Management**: React Hooks (`useState`, `useEffect`, etc.)

---

## 📱 画面構成・URLルート

- **顧客用オーダー画面**: `http://localhost:5173/?seat=1` （※クエリパラメータで席番号シミュレーション可能）
- **キッチンディスプレイ画面**: `http://localhost:5173/kitchen`
